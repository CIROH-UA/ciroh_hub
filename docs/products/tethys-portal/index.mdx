# CIROH Tethys Portal

The [CIROH Tethys Portal](https://tethys.ciroh.org) hosts web apps built by the CIROH community on [Tethys Platform](https://www.tethysplatform.org/). It runs on CIROH's AWS account.

## Signing in

Sign in at [tethys.ciroh.org](https://tethys.ciroh.org) with your [HydroShare](https://www.hydroshare.org/) account. The apps hosted on their own address (listed below) use the same sign-in, so you only log in once.

## Adding or updating an app

Open an issue on [CIROH-UA/tethysportal-ciroh](https://github.com/CIROH-UA/tethysportal-ciroh/issues/new/choose) with the **Add a new app** or **Update an app** form. A portal maintainer reviews the request.
