The NGIAB-NRDS Ecosystem provides a wide range of tools and scaffolding for the NextGen Water Resources Modeling Framework ([NextGen](https://github.com/NOAA-OWP/ngen)).
NextGen In A Box (NGIAB) provides a research-grade NextGen environment that can be deployed in as few as five minutes,
while the NextGen Research Datastream (NRDS) offers a vision of modular, composable operational deployment of multiple concurrent datastreams.

For a high-level introduction to the NGIAB-NRDS Ecosystem, please visit the [NGIAB Website](https://ngiab.ciroh.org).
