The Community FIM Ecosystem offers open-source tools for generating, simulating, evaluating, benchmarking, and observing flood inundation maps — from operational forecast to validated science.

For a high-level introduction to the Community FIM Ecosystem, please visit the [FIM Ecosystem Website](https://sdml.ua.edu/fim-ecosystem/).
